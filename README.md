# Quotes Author Details Scraper

This Python project scrapes quotes and author information from quotes.toscrape.com.

## Features

- Scrapes quotes text
- Extracts author names
- Visits author pages
- Extracts author birth date
- Extracts author location
- Handles pagination
- Saves data to JSON file

## Technologies Used

- Python
- requests
- BeautifulSoup
- JSON

Built as part of my Python and web scraping learning journey.
